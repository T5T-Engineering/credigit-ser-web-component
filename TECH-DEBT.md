# Tech debt — @credigit/web-ui

Register of temporary exceptions to the project invariants (invariant 8: no hard-coded values; plus missing tests and known API gaps). Every literal default that stands in for a business rule carries its TD id in a code comment next to the literal. Consuming apps must pass the real value from the Rules & Parameters engine / tenant configuration; the library default exists only so a component renders on its own (playground, tests).

Status: **Open** (still in the code), **Accepted** (deliberate, documented exception — not expected to change), **Closed** (resolved; kept for history).
